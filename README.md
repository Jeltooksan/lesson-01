# Мобильное клиентское приложение (React Native / Expo)

Учебный проект, представляющий собой frontend-часть мобильного приложения. Главная цель проекта — разработка пользовательского интерфейса с акцентом на систему регистрации и аутентификации (в настоящий момент модуль находится в стадии доработки), а также демонстрация работы с состоянием (state) на примере клиентского каталога.

## 🌟 Текущий функционал и статус

- **Система регистрации и авторизации (В разработке):** Создание экранов для регистрации новых пользователей и входа в систему мобильного приложения. 
- **Интерактивный UI:** Кроссплатформенный интерфейс с использованием современных подходов к стилизации мобильных компонентов.
- **Демонстрационный каталог:** Реализована логика фильтрации элементов по категориям для демонстрации работы алгоритмов на клиенте.
- **Уведомления:** Настроена система временных всплывающих уведомлений.

## ⚙️ Требования к окружению (Что нужно установить до запуска)

Так как это мобильное приложение на базе React Native и фреймворка Expo, для его запуска на компьютере (в режиме симуляции Android) требуется предварительная настройка среды разработки.

### 1. Node.js
- **Зачем нужно:** Для работы пакетного менеджера `npm`, который скачивает зависимости проекта и запускает локальный сервер Expo.
- **Действие:** Скачайте и установите LTS-версию с официального сайта [nodejs.org](https://nodejs.org/).

### 2. Android Studio (Для запуска на эмуляторе)
- **Зачем нужно:** Android Studio предоставляет необходимые SDK (инструменты разработчика Android) и виртуальное устройство (эмулятор телефона), на котором будет отображаться приложение.
- **Действие:** 
  1. Скачайте и установите **Android Studio** с официального сайта.
  2. При первом запуске пройдите стандартную установку (Standard Setup), чтобы программа скачала базовый Android SDK.
  3. В стартовом окне Android Studio откройте **Virtual Device Manager** (или AVD Manager) и создайте виртуальное устройство (например, Pixel 6 с последней версией Android).
  4. Запустите созданный эмулятор, нажав кнопку "Play" (треугольник) в Device Manager. Эмулятор должен быть включен до запуска проекта.

### 3. Приложение Expo Go (Альтернатива эмулятору)
- Если ваш компьютер не "тянет" Android Studio, вы можете запустить приложение прямо на своем физическом смартфоне.
- **Действие:** Скачайте приложение **Expo Go** из Google Play (для Android) или App Store (для iOS).

## 🚀 Создание и запуск приложения на React Native (Expo)
Шаг 1. Проверка установленных инструментов (Задание 1)
Перед началом работы убедитесь, что у вас установлены все необходимые программы.

Откройте встроенный терминал в вашем редакторе кода (в VS Code это делается через меню Terminal → New Terminal).

Выполните по очереди следующие команды и запишите полученные цифры (версии) в свой отчет:

Проверка Node.js:

Bash
node -v
Проверка npm:

Bash
npm -v
Проверка Git:

Bash
git --version
Шаг 2. Создание пустого приложения (Задание 2)
В терминале перейдите в ту папку на компьютере, где хотите сохранить проект.

Выполните команду для генерации нового проекта с названием lesson-01 на базе TypeScript:

Bash
npx create-expo-app@latest lesson-01 --template blank-typescript
Дождитесь окончания загрузки всех файлов.

Шаг 3. Запуск локального сервера
Перейдите в папку только что созданного проекта с помощью команды:

Bash
cd lesson-01
Запустите сервер Expo:

Bash
npx expo start
Дождитесь, пока в терминале сгенерируется и появится большой QR-код.

Шаг 4. Открытие приложения на телефоне
Установите и откройте приложение Expo Go на вашем смартфоне.

Отсканируйте QR-код из терминала (на Android используйте сканер внутри самого Expo Go, на iOS можно использовать стандартную камеру).

Дождитесь загрузки проекта на экране телефона (процесс сборки будет отображаться в терминале).

⚠️ Решение частых проблем (Если QR-код не работает)
Если телефон выдает ошибку сети или не может подключиться к компьютеру, остановите текущий сервер в терминале (нажмите Ctrl + C) и попробуйте один из следующих вариантов:

Вариант А (Запуск через глобальный туннель): Помогает, если телефон и ПК находятся в разных сетях Wi-Fi.

Bash
npx expo start --tunnel
Вариант Б (Запуск в браузере): Если нужно просто посмотреть интерфейс прямо на компьютере.

Bash
npx expo start --web
