# Клиентское веб-приложение

Учебный проект, представляющий собой frontend-часть веб-приложения. Главная цель проекта — разработка пользовательского интерфейса с акцентом на систему регистрации и аутентификации (в настоящий момент модуль находится в стадии доработки), а также демонстрация работы с состоянием (state) на примере клиентского каталога.

## 🌟 Текущий функционал и статус

- **Система регистрации и авторизации (В разработке):** Создание экранов для регистрации новых пользователей и входа в систему. 
- **Интерактивный UI:** Сверстанный интерфейс главной страницы с использованием современных подходов к стилизации и типографике.
- **Демонстрационный каталог:** Реализована логика фильтрации элементов по категориям (без перезагрузки страницы) для демонстрации работы алгоритмов на клиенте.
- **Уведомления (Toast):** Настроена система временных всплывающих уведомлений, автоматически исчезающих по таймеру (через 3 секунды) при взаимодействии с элементами.

## 🛠 Использованные технологии

- **React (Functional Components & Hooks)** — управление состояниями (`useState`) и рендеринг интерфейса.
- **JavaScript (ES6+)** — логика взаимодействия, фильтрация массивов и работа с таймерами.
- **CSS / Inline Styles** — визуальное оформление, псевдоклассы и импорт внешних шрифтов.
